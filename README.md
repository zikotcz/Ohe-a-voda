# Mlok a Žabka – Zapomenuté doly

Kooperativní plošinovka pro dva hráče na jedné klávesnici. Celá hra je v souboru `index.html`.

Hrát online: https://zikotcz.github.io/Ohe-a-voda/

## Ovládání

- **Mlok (oheň):** šipky ← ↑ →
- **Žabka (voda):** A / W / D
- **R** restart levelu, **Esc** menu, **M** zvuk

Láva zabije Žabku, voda Mloka, zelený sliz oba. Level končí, když oba stojí u svých dveří.
